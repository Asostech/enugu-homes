# 🏠 Enugu Homes

> A real estate listing platform for Enugu and Nsukka — where agents list properties and buyers/tenants find their next home.

🌐 Live Site: [enugu-homes](https://asostech.github.io/enugu-homes/enugu-homes/)

 About
Enugu Homes is a property listing web platform built specifically for the Enugu State real estate market. It connects:
Real estate agents— list houses, land, and properties for sale or rent
🔍Buyers & Tenants— browse available properties and contact agents directly

Think of it as a local Craigslist/Jiji — but built specifically for Enugu and Nsukka.

✨ Features

📋 Property listing for agents
🏘️ Browse properties for rent and sale
📍 Location-based listings (Enugu & Nsukka)
📞 Direct contact between buyers and agents
📱 Responsive design — works on mobile and desktop

🛠️ Built With
HTML5 — Structure & layout
CSS3 — Styling & responsive design
JavaScript — Interactivity
GitHub Pages — Hosting & deployment
